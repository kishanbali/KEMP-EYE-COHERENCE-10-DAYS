# KEMP EYE 👁 COHERENCE — 10 DAYS

A mobile-first 10-day sound experience. Each session is designed for approximately 10 minutes.

## Experience

- 10 daily sessions
- Minimal participant interface
- No narration
- No binaural beats
- No tuning forks
- Tibetan and crystal singing-bowl source recordings
- © KishanBali — KEMP Wisdom Publications

## Deployment

The site is a static web app and can be published with GitHub Pages. The production build should place the final licensed audio files at `audio/day-1.mp3` through `audio/day-10.mp3`, then update the player mapping to those local files.
